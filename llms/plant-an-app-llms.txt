# Plant an App

> Plant an App is a developer-first low-code application development platform used to build case management systems, citizen service portals, workflow automation, compliance dashboards, and legacy-system integrations. It is positioned for government agencies, federal missions, and contractors, and is hosted on Amazon Web Services. Backed by 500 Global.

This llms.txt was generated by the API Evangelist enrichment pipeline from the company's public surface. Plant an App does not publish a public REST API reference or OpenAPI specification; it is a low-code builder platform documented for app builders rather than an API product.
